Floppy Custom Kernel - CHANGELOG
================================

Target Device
- Redmi Note 8 / 8T (ginkgo / willow)

Build Base
- Source: FlopKernel-Series/flop_trinket-mi_kernel
- Branch: floppy-new
- Kernel: 4.14.356 (non-GKI)

Integrated Features
- KernelSU support (from source base)
- SUSFS support (from source base)
- Droidspaces config fragment added:
  - Namespaces (PID/UTS/IPC/USER/NET)
  - Cgroups + MEMCG
  - OverlayFS + firmware loader
  - Netfilter/NAT, VETH, bridge, routing tables

Build/Compatibility Fixes
- Defconfig flow set to:
  - vendor/trinket-perf_defconfig (base)
  - vendor/ginkgo.config (device fragment)
  - droidspaces.config (extra fragment)
- Stack protector strong mode disabled for compiler compatibility:
  - CONFIG_CC_STACKPROTECTOR_NONE=y
  - CONFIG_CC_STACKPROTECTOR_STRONG not set
- LLVM Polly disabled to avoid unsupported clang flags:
  - CONFIG_LLVM_POLLY not set
- Build script updated to use LLVM integrated assembler:
  - LLVM=1
  - LLVM_IAS=1

Output Artifacts
- out/arch/arm64/boot/Image.gz-dtb
- out/dtbotmp/dtbo.img
- out/arch/arm64/boot/dts/xiaomi/qcom-base/trinket.dtb
- Flashable ZIP (AnyKernel3 packaging):
  - Floppy_custom-ginkgo-<date-time>.zip

Important Note
- Before flashing, always backup Boot + DTBO in TWRP.
